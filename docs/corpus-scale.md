## 批量做法

- **候选台账。** 先按平台 ID 记录发布来源和标题线索。按实际对话内容核对主播与发布者，以及整场和切片的重叠。成库规模按独立连麦和案例分别统计。
- **从原片到 Script。** 优先取得公开可播放的音频，下载后解码并做 SHA-256，再用本机 Whisper 生成带秒数的转写。批次状态逐条保存，已经成功的音频和转写可复用，失败的可以指定重试。
- **两种检索用途。** 本机研究窗供找证据和做新卡。来源有时码才返回时码，否则返回原文字符位置。聊天工具使用带情境、接话动作和原片时码的合格短卡。完整转写不进入部署快照。
- **真实扩库。** 以每位先筛出 100 场独立连麦为首个规模目标，再扩至几百。目录按场次去重，核对动作与时间，每批增量跑同一套新旧检索和无答案题。现阶段只有鳌烨的研究文本量达到几百，八个聊天库都未达到百条。

桌面项目根目录可执行以下采集与研究索引命令。脚本读取本机逐条候选清单与归档。

```sh
export PYTHONPATH=mvp/src
mvp/.venv/bin/python -m yuelao_mvp.corpus_batch acquire --host tianshu --per-host 20 --audio-only --plan
mvp/.venv/bin/python -m yuelao_mvp.corpus_batch acquire --host tianshu --per-host 20 --audio-only
mvp/.venv/bin/python -m yuelao_mvp.script_archive
mvp/.venv/bin/python -m yuelao_mvp.script_research build
mvp/.venv/bin/python -m yuelao_mvp.script_research search-passages '婆婆 一块儿 一起住' --host guolu --timed-only
```

## 哪些测试已经过了

- 115 项自动测试通过，535 份归档哈希匹配，41 张聊天卡的时码和引用来源均通过核验。HTTP 复跑 23 条旧题和 4 条新增题通过。 [本机 HTTP 与归档核验](acceptance-v0.3.1.json)
- 33 个固定评测组合中，16 条有目标原片的题，首位原片加时码命中 15 条。8 条相关无匹配中正确返回空 6 条。天书催婚的同义问法仍漏检，曲曲和郭律各有一条误候选。 [检索覆盖与错误](rag-evaluation.md) · [当前快照复跑](../evals/rag-regression-v0.3.1.json)
- 8 个主播各加入 1,000 张模拟卡做本机压力测试，120 次查询的目标命中、同主播过滤及无关题返回空均通过。按场景计算的最慢 p95 为 **16.52 毫秒**。这是检索容量测试，真实内容覆盖及答复质量需用独立连麦评估。 [压力复跑脚本](../evals/rag-scale-smoke.py) · [实测数据](../evals/rag-scale-v0.3.1.json)
