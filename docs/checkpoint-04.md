# 进展点 04 · 同场回放与试聊反馈

已核验 501 份归档 Script 的哈希、499 份研究索引、26 张案例卡的时码和 12 条检索回归。用五场真实连麦做独立首轮文本回放。鳌烨留存样本中，原片先建议多接触几个人，插件先问是否长期在北京。天书原片先区分双方各自还想不想约，插件直接问有没有定下次。老林、杰哥和郭律的开发样本接法相近。原片是自动转写证据，原声节奏和说话人待核听。 [完整对照](replay-v0.2.7.md) · [归档核验](archive-audit-v0.2.7.json)

v0.2.8 接入反馈网页。用户可以只给评分，也可以写具体哪一轮、哪里出戏、希望怎么改。附对话摘录需自行勾选并编辑，提交后才进作者收件箱。语音听写可用时先转成可编辑的文字。页面已用合成反馈测试落库和回执，未勾选的摘录未入库。收件箱限站点作者登录。 [试聊反馈](https://yuelao-trial-feedback.arthurqiu50.chatgpt.site/) · [作者收件箱](https://yuelao-trial-feedback.arthurqiu50.chatgpt.site/inbox) · [隐私说明](https://yuelao-trial-feedback.arthurqiu50.chatgpt.site/privacy)

插件提供聊完时的反馈链接和原片卡上的按钮。链接只携带版本号和所选聊法。网站有即时收件箱，作者可以按版本和具体问题复盘。ChatGPT 账号内的证据卡和浏览器麦克风权限仍需实测。ChatGPT 内建的赞踩和账户对话历史不用于这个反馈机制。 [OpenAI 插件数据规则](https://developers.openai.com/plugins/plugin-guidelines#tool-data-handling)
